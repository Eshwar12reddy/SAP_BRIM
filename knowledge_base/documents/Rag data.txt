ARTIFICIAL INTELLIGENCE (AI)

Artificial Intelligence (AI) is a branch of computer science that focuses on creating intelligent machines capable of performing tasks that normally require human intelligence. AI systems can learn from data, recognize patterns, solve problems, make decisions, understand natural language, and interact with humans. AI is used in healthcare, finance, education, transportation, agriculture, robotics, gaming, cybersecurity, and many other industries.

MACHINE LEARNING (ML)

Machine Learning is a subset of Artificial Intelligence. Instead of being explicitly programmed, machine learning models learn patterns from data. The learning process involves collecting data, preprocessing it, selecting features, training a model, evaluating its performance, and making predictions.

Machine Learning is divided into three main categories:
1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning

Common supervised learning algorithms include:
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

Common unsupervised learning algorithms include:
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN
- Principal Component Analysis (PCA)

DEEP LEARNING

Deep Learning is a subset of Machine Learning that uses Artificial Neural Networks with multiple hidden layers. Deep Learning models automatically learn complex features from data without manual feature engineering.

Applications include:
- Image Classification
- Object Detection
- Face Recognition
- Speech Recognition
- Language Translation
- Medical Image Analysis
- Autonomous Vehicles

NEURAL NETWORKS

A Neural Network consists of three main layers:
1. Input Layer
2. Hidden Layer(s)
3. Output Layer

Each neuron receives input values, applies weights and bias, uses an activation function, and produces an output. During training, weights are updated using backpropagation and an optimizer.

EMBEDDINGS

Embeddings are numerical vector representations of text, images, or other data. Similar information has similar vectors. Embeddings help AI systems understand semantic meaning instead of exact keyword matching.

VECTOR DATABASES

- FAISS
- Pinecone
- Weaviate
- Milvus

Advantages:
- Fast retrieval

RETRIEVAL-AUGMENTED GENERATION (RAG)

RAG combines information retrieval with Large Language Models.

Workflow:
1. Load documents.
2. Split documents into chunks.
3. Generate embeddings.
4. Store embeddings in a vector database.
5. Convert the user's question into an embedding.
6. Retrieve the most similar document chunks.
7. Send the retrieved information to the LLM.
8. Generate the final answer.

Advantages:
- More accurate answers
- Uses private documents
- Reduces hallucinations
- Provides up-to-date information
